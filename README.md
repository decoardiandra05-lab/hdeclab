# H DEC LAB | Engineering Portfolio Exhibition

Welcome to the official portfolio repository of **H DEC LAB**. This is an electro-mechanical research and development environment focused on creating smart, reliable, and integrated automation systems.

## 🔬 Core Expertise & Technical Tools
* **Design 2D/3D:** Autodesk Inventor & AutoCAD for high-precision mechanical casing models.
* **Electronic Engineering:** Custom PCB schematic design, components routing, and hardware prototyping.
* **Smart Automation & IoT:** Embedded system control, sensors calibration, and ecosystem syncing (Blynk, Arduino Cloud).
* **Programming Languages:** Core firmware development using C/C++ via Arduino IDE and VS Code.

## 📁 Project Exhibition Archive inside this Repository
1. **AirGuard AQMS System** (`proyek1.jpeg`) - Air quality monitoring enclosure made with high-precision clear acrylic sheets.
2. **Climate Monitoring Box** (`proyek2.jpg`) - Portable weather station embedded in a heavy-duty black enclosure with interactive dashboard data syncing.
3. **Mechanical Robot Enclosure** (`proyek3.jpeg`) - A 3D rendered protective case for complex robotic circuits.
